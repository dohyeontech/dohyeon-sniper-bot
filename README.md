장세 탓이 아니었습니다. v5.0은 이 진단을 규칙으로 바꿔 넣었습니다.

### v5.0 공통 규칙 (재설계·신규 전략에 적용)

1. **변동성 게이트** — 10분 레인지가 전략별 하한(0.3~1.0%) 미만이면 진입 금지. 대형주는 자동 제외.
2. **비용 게이트** — 목표 익절폭 < 왕복 실비용(수수료 0.10% + 호가 1틱) × 5 이면 진입 금지.
   128원 종목은 1틱이 **0.78%**라 왕복 실비용이 0.88% — 이런 종목은 2% 목표로도 손익비가 서지 않습니다.
3. **1일 거래 상한** — 전략별 하루 청산 10~14회. 거래 빈도 자체가 비용이던 구조를 끊습니다.
4. **체결 모델** — 매수 = 관측가 **+0.5틱**, 매도 = 관측가 **-0.5틱**(왕복 호가 1틱).
   v4.0까지는 스프레드를 0으로 가정해 실제보다 낙관적이었습니다.
5. **동일 종목 재진입 쿨다운** — 재설계·신규 전략은 청산 사유와 무관하게 15~20분 재진입 금지.

- **정체 청산을 빼는 이유** — 6분 만에 손익 0 근처에서 끊으면 왕복 비용(0.2~0.5%)을 넘길 시간이 없습니다.
  실제로 v5.1의 밤 청산 33건은 전부 수수료·호가만 남기고 끝났고 목표 달성은 0건이었습니다.
  방향이 없는 구간은 12분(`panic_bounce` 15분 · `tape_sweep` 8분) 상한까지 두고,
  그 사이에 목표/트레일링/손절 중 하나가 결정되게 합니다.
- **목표를 낮춘 이유** — 횡보·약세 변동성 장에서 +2.2%는 찍히지 않습니다. +1.5% 목표에 +0.9% 트레일링을 걸면
  고점 대비 -0.30%에서 이익이 확정되고, 손절은 -1.3%로 짧아 승률 50%만으로도 기대값이 양수가 됩니다.
- **3m·10m에도 비용 게이트 적용** — 목표가 +1.5~+1.6%로 내려오면서 1틱이 비싼 저가 종목(왕복 0.5%↑)은
  목표를 다 맞춰도 손익비가 서지 않습니다. v5.2부터 3m·10m도 `목표 ≥ 왕복 실비용 × 5` 게이트를 통과해야 진입합니다.
- v5.1에서 고친 `alt_rs` 180초 관측 버그와 `panic_bounce` 손절 -1.3%는 그대로 유지합니다.

**스테이블코인 전면 제외 (`market_filter.py`)** — `KRW-USDT`·`KRW-USDC`·`KRW-DAI` 등 달러·유로 페그

체결 가정: 목표 익절은 목표가 체결(초과분 미반영·보수적), 손절·트레일링·시간초과는 관측 틱 가격에서

### 상태 승계·보호 규칙

- v4.0 상태를 읽으면 `3m`·`10m`·`panic_bounce`는 규칙·잔고·전적·포지션을 **손대지 않고** 승계하고,
  `30m`·`pullback_reentry`·`vwap_breakout`·`bb_squeeze`는 잔고·전적만 승계한 뒤 규칙을 교체합니다
  (재설계 시점에 물려 있던 포지션은 다음 틱에 `RESET_EXIT`으로 정리). 퇴출 3전략은 `v4_archive`에 보존되고
  신규 3전략은 200만 원으로 시작합니다.
- **v5.0 → v5.1 → v5.2 → v5.3**은 `migrate_from_v5()`로 **무손실 승계**합니다 — 9계좌 잔고·전적·포지션·매매내역·쿨다운과
  `v4_archive`·v4→v5 승계 이력·`v5_fix`·`v5_2_fix`를 그대로 이어받고, 규칙 파라미터만 v5.3 정의로 교체합니다.
  퇴출한 `alt_rs`는 `v5_2_archive`에 성적표를 남기고, 그 계좌(2,000,000원 시드 · 1,573,491원 잔고)는
  `confirmed_surge`가 승계합니다. 파라미터가 실제로 바뀐 계좌만 1일 거래·손실 예산 시계
  (`rules_effective_from`·`day_start_equity`)를 승계 시점으로 옮기고, 내역은 상태의 `v5_3_fix`에 기록됩니다.
- Gist가 설정된 환경에서 원격 상태 로드에 실패하면 **매매도 원격 저장도 하지 않고**(`STATE_SYNC_WAIT`)
  5초 간격으로 재시도합니다. 낡은 로컬 파일이 라이브 전적을 덮어쓰는 사고를 막는 장치입니다.
