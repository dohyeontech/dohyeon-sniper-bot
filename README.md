# 🎯 도현의 테크브리프 · 가상 거래량 스나이퍼 봇 (24/7 Cloud)

업비트 원화 마켓 70~80개 활성 알트코인을 상시 스캔하여, 5분봉 거래량 급증(+220% 이상) 포착 시 자동 진입/탈출하는 무중단 가상 트레이딩 봇 & 실시간 웹 대시보드입니다.

## 🚀 아키텍처
- **호스팅:** Render Free Web Service (Python FastAPI)
- **가동 유지:** Cloudflare Worker Cron Trigger (10분 주기 `/health` Keep-Alive Ping)
- **대시보드:** 모바일 반응형 실시간 포트폴리오 웹 (`GET /dashboard`)
- **데이터 보존:** GitHub Gist API / 원격 동기화

## ⚙️ 4대 기계적 트레이딩 규칙
1. **진입 조건:** 5분봉 거래량이 1시간 평균 대비 2.2배(220%) 이상 폭발 + 양봉 돌파
2. **목표 익절:** +2.0% 도달 시 전량 청산
3. **트레일링 스탑:** +1.5% 도달 후 고점 대비 -0.5% 반락 시 수익 보존 청산
4. **리스크 관리:** -1.2% 기계적 칼손절 / 최대 보유 시간 30분 제한
