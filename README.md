# 🏆 도현의 테크브리프 · 10대 단타 전략 실시간 비교 리그 v4.0 (24/7 Cloud)

업비트 실시간 체결(WebSocket trade) 스트림 **1개**를 받아 **1.5초 주기**로 시장을 판단하고,
잔고·포지션·전적·쿨다운이 **완전히 분리된 10개 가상 계좌**를 동시에 운용하는 모의투자 리그 +
실시간 웹 대시보드입니다. 실계좌·실주문은 없습니다.

## 🏟️ 리그 구조 — 10전략 × 각 2,000,000원 (총 2,000만 원)

같은 시장 데이터를 모든 전략이 공유하므로 **"같은 순간에 어떤 규칙이 돈을 버는가"** 를
조건이 동일한 상태에서 비교할 수 있습니다. v3.1의 3계좌는 잔고·전적·포지션을 그대로 승계했습니다.

**공통 리스크 규칙** — BTC 15분봉 20이평 대비 **-0.2% 초과 하회** 시 전 전략 신규 진입 차단(보유 유지).
손절 시에만 전략별 쿨다운(3~5분)이 걸리고, 그 쿨다운도 계좌별로 독립입니다.

체결 가정: 목표 익절은 목표가 체결(초과분 미반영·보수적), 손절·트레일링·시간초과는 관측 틱 가격 체결
(슬리피지 반영). 수수료 왕복 0.05%.

## 🚀 아키텍처

- **호스팅:** Render Free Web Service (Python FastAPI) — 수동 배포(`Clear build cache & deploy`)
- **가동 유지:** 10분 주기 `/health` 핑
- **WebSocket:** `ws_stream.py` 1개 (유의종목 제외 · 24h 거래대금 30억↑ · 15분 롤링 윈도우)
- **1분봉 캐시:** `candles.py` — 거래대금 상위 **15종목만** 별도 저속 스레드가 **종목당 60초 주기**,
  요청 간 **0.25초 슬립**(실효 4 req/s ≤ 업비트 10 req/s)으로 순환 수집 → RSI·볼린저 전략용
- **대시보드:** `GET /dashboard` — 수익률 리더보드(1~10위) + 전략 카드 + 전략별 상세(포지션·규칙·매매내역)
- **상태 API:** `GET /api/status` — `strategies`(10전략 전체), `leaderboard`, `aggregate`, `tiers`(승계 3계좌 별칭)
- **데이터 보존:** 비공개 GitHub Gist 동기화 (`GIST_TOKEN`, `GIST_ID` 환경변수 전용), 60초 스로틀 + 체결 시 즉시 저장

### 상태 승계·보호 규칙

- v3.1 상태(3계좌)를 읽으면 `3m`·`10m`·`30m`의 잔고·전적·보유 포지션·쿨다운·매매내역을 **손대지 않고**
  같은 키 슬롯으로 옮기고, 신규 7전략만 200만 원 신규 시드로 시작합니다(`migrate_from_v3`).
- Gist가 설정된 환경에서 원격 상태 로드에 실패하면 **매매도 원격 저장도 하지 않고**(`STATE_SYNC_WAIT`)
  5초 간격으로 재시도합니다. 낡은 로컬 파일이 라이브 전적을 덮어쓰는 사고를 막기 위한 장치입니다.
