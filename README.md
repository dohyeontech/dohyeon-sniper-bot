# 🏆 도현의 테크브리프 · 단타 전략 실시간 비교 리그 v5.2 (24/7 Cloud)

업비트 실시간 체결(WebSocket trade) 스트림 **1개**를 받아 **1.5초 주기**로 시장을 판단하고,
잔고·포지션·전적·쿨다운이 **완전히 분리된 10개 가상 계좌**를 동시에 운용하는 모의투자 리그 +
실시간 웹 대시보드입니다. **실계좌·실주문·API 키는 없습니다** (시세 조회만 합니다).

## 🔬 v5.0 개편 — v4.0 실거래 390건 진단에서 출발

v4.0 리그를 12시간 돌린 실거래 기록을 청산 사유·종목군·비용으로 분해한 결과:

| 관찰 | 수치 |
|---|---|
| 최근 200청산의 **가격손익** | **+119,993원** (방향은 맞았다) |
| 같은 구간 **수수료** | **378,008원** (왕복 0.10% × 200회) |
| 결과 | **-258,015원** — 손실의 정체는 비용 |
| **대형주**(BTC·ETH·XRP·SOL·DOGE 등) 70건 | 청산의 **90%가 시간초과**, 건당 **-0.141%**, 합계 **-313,638원** |
| **알트** 130건 | 건당 **+0.135%**, 합계 **+55,623원** |

즉 **BTC의 20분 변동(0.2~0.4%)에 목표 1.5~2.5%를 건 유니버스·밴드 불일치**가 원인이었고,
장세 탓이 아니었습니다. v5.0은 이 진단을 규칙으로 바꿔 넣었습니다.

### v5.0 공통 규칙 (재설계·신규 전략에 적용)

1. **변동성 게이트** — 10분 레인지가 전략별 하한(0.3~1.0%) 미만이면 진입 금지. 대형주는 자동 제외.
2. **비용 게이트** — 목표 익절폭 < 왕복 실비용(수수료 0.10% + 호가 1틱) × 5 이면 진입 금지.
   128원 종목은 1틱이 **0.78%**라 왕복 실비용이 0.88% — 이런 종목은 2% 목표로도 손익비가 서지 않습니다.
3. **1일 거래 상한** — 전략별 하루 청산 10~14회. 거래 빈도 자체가 비용이던 구조를 끊습니다.
4. **체결 모델** — 매수 = 관측가 **+0.5틱**, 매도 = 관측가 **-0.5틱**(왕복 호가 1틱).
   v4.0까지는 스프레드를 0으로 가정해 실제보다 낙관적이었습니다.
5. **동일 종목 재진입 쿨다운** — 재설계·신규 전략은 청산 사유와 무관하게 15~20분 재진입 금지.

## 🔧 v5.2 정비 — v5.1 밤사이 190전 51승 139패(-133만 원) 진단

v5.1을 밤새 돌린 라이브 기록에서 **청산 방식 자체가 손실을 만들고 있었다**는 것이 드러났습니다.
**10계좌의 잔고·전적·포지션은 하나도 버리지 않고 그대로 이어받습니다** (v5.1 → v5.2 무손실 승계).

| 관찰 | 수치 | v5.2 조치 |
|---|---|---|
| **6분 무풍 정체 청산** | 최근 청산 60건 중 **33건(-86,026원)**, 목표 달성은 **0건** | `STAGNATION` 청산 로직·파라미터 **전면 제거** — 손절·목표·트레일링·보유시간 상한으로만 청산 |
| 목표가가 멀었다 | +2.0~+2.5% 목표에 도달 0건, 시간초과 15건(-68,305원) | 모멘텀·돌파 6전략 목표 **+1.4~+1.7%** · 트레일 **+0.9~+1.0%**(고점 -0.30~-0.35%) · 손절 **-1.2~-1.4%** |
| `3m`이 밤 손실의 26% | 125전 **-49.06%** — 15초 300만 원 문턱의 허매수 진입 | 15초 거래대금 **800만↑** · BID **78%↑** · 1일 **10회** |
| `alt_rs` 승률 최하위 | 16전 3승 13패(**18.8%**) | 디커플링 **+1.3%p↑** · 15초 **700만↑** · BID **75%↑** · 1일 **6회** |
| `panic_bounce` 손익비 | 트레일 발동 +1.6%가 목표 +2.0%에 붙어 이익을 못 챙겼다 | 목표 **+1.8%** · 트레일 **+1.2%**(고점 -0.35%) · 손절 **-1.25%** |
| `30m` · `tape_sweep` | 30m 최근 7건 **-1,056원**(거의 본전) · tape_sweep 목표 +1.8%/손절 -1.0%/8분 | **규칙 유지** (1일 거래 예산 시계도 유지) |

- **정체 청산을 빼는 이유** — 6분 만에 손익 0 근처에서 끊으면 왕복 비용(0.2~0.5%)을 넘길 시간이 없습니다.
  실제로 v5.1의 밤 청산 33건은 전부 수수료·호가만 남기고 끝났고 목표 달성은 0건이었습니다.
  방향이 없는 구간은 12분(`panic_bounce` 15분 · `tape_sweep` 8분) 상한까지 두고,
  그 사이에 목표/트레일링/손절 중 하나가 결정되게 합니다.
- **목표를 낮춘 이유** — 횡보·약세 변동성 장에서 +2.2%는 찍히지 않습니다. +1.5% 목표에 +0.9% 트레일링을 걸면
  고점 대비 -0.30%에서 이익이 확정되고, 손절은 -1.3%로 짧아 승률 50%만으로도 기대값이 양수가 됩니다.
- **3m·10m에도 비용 게이트 적용** — 목표가 +1.5~+1.6%로 내려오면서 1틱이 비싼 저가 종목(왕복 0.5%↑)은
  목표를 다 맞춰도 손익비가 서지 않습니다. v5.2부터 3m·10m도 `목표 ≥ 왕복 실비용 × 5` 게이트를 통과해야 진입합니다.
- v5.1에서 고친 `alt_rs` 180초 관측 버그와 `panic_bounce` 손절 -1.3%는 그대로 유지합니다.

## 🏟️ 리그 구조 — 10전략 × 각 2,000,000원 (총 2,000만 원)

**잔고·전적을 승계하는 3계좌**(`3m`·`10m`·`panic_bounce`)는 v4.0부터 이어진 같은 계좌입니다.
개편 효과를 같은 조건에서 나란히 비교하기 위해 기록을 끊지 않습니다.

| # | 키 | 전략 | 구분 | 진입 | 청산 |
|---|---|---|---|---|---|
| 1 | `3m` | 300만↑ 급등 추격 | 승계·재조정 | 15초 거래대금 **800만↑** · 직전 3분 평균 4.0배 · BID **78%↑** · 3분 +0.3~+3.0% | **+1.5%** / 트레일 **+0.9%→-0.30%** / **-1.3%** / 12분 / 1일 10회 |
| 2 | `10m` | 1,000만↑ 급등 추격 | 승계·재조정 | 위와 같되 15초 거래대금 1,000만↑ | **+1.6%** / 트레일 **+0.95%→-0.32%** / **-1.35%** / 12분 |
| 3 | `30m` | 대형주 10분 레인지 역추세 | 재설계 | 24h TOP10 대형주 · 10분 고점 대비 -0.35~-1.2% 눌림 + 15초 BID 62%↑ + 반등 0.05%↑ | +0.75% / 트레일 +0.50%→-0.20% / -0.50% / 12분 |
| 4 | `panic_bounce` | 투매 과매도 반등 | 승계·재조정 | 3분 -2.5%↓ 급락 후 15초 BID 65%↑ + 직전 15초 대비 반등 | **+1.8%** / 트레일 **+1.2%→-0.35%** / **-1.25%** / 15분 / 손절 후 동일종목 15분 |
| 5 | `pullback_reentry` | 눌림목 재진입 | 재설계 | 3분 +0.5%↑ 상승 후 고점 대비 -0.8~-2.0% 눌림 · 10분 레인지 1.0%↑ · BID 62%↑ + 상승 전환 | **+1.7%** / 트레일 **+1.0%→-0.35%** / **-1.4%** / 12분 |
| 6 | `vwap_breakout` | 실시간 VWAP 돌파 | 재설계 | 3분 VWAP 하단 → 거래대금 3.0배↑ + BID 62%↑ 로 VWAP +0.35%↑ 돌파 · 10분 레인지 1.0%↑ | **+1.5%** / 트레일 **+0.9%→-0.30%** / **-1.25%** / 12분 |
| 7 | `bb_squeeze` | 볼린저 스퀴즈 돌파 | 재설계 | BB(20,2) 수축(하위 20%) + 종가 > 중심선 + 상단 밴드 거래량 2.0배↑ · 10분 레인지 0.9%↑ | **+1.6%** / 트레일 **+0.95%→-0.32%** / **-1.3%** / 12분 |
| 8 | `box_breakout` | 10분 박스권 돌파 | **신규** | 박스 폭 1.1%↓ 수축 후 박스 고점 +0.15% 돌파 · 거래대금 3.0배↑ · BID 65%↑ | **+1.4%** / 트레일 **+0.9%→-0.30%** / **-1.2%** / 12분 |
| 9 | `alt_rs` | 알트-BTC 디커플링 강세 | **신규** | 3분 수익률이 BTC 대비 **+1.3%p↑** · 15초 **700만↑** · BID **75%↑** · 10분 레인지 0.8%↑ | **+1.6%** / 트레일 **+0.95%→-0.32%** / **-1.3%** / 12분 / 1일 6회 |
| 10 | `tape_sweep` | 대형 매수 체결 스파이크 | **신규** | 10초 단일 매수 체결 300만↑ & 3분 평균의 4배↑ + 15초 +0.12%↑ · BID 60%↑ | +1.8% / 트레일 +1.1%→-0.3% / -1.0% / **8분** |

- **`box_breakout`** — 좁게 수축한 박스의 상단을 거래대금이 실리며 넘는 자리는 손절선(박스 하단)이
  가까워 손익비가 좋습니다. 15초 급등 상한을 둬 "이미 오른 뒤 추격"을 막습니다.
- **`alt_rs`** — BTC가 제자리이거나 밀리는 동안 그 종목만 앞서는 구간은 자금 로테이션의 흔적입니다
  (BTC는 알트 변동의 절반만 설명하고 리더십이 순환). BTC 자신은 대상에서 제외합니다.
- **`tape_sweep`** — 집계 매수비율이 아니라 **단일 대형 매수 체결(스윕)** 을 봅니다. 체결 방향 불균형은
  1~5분 수익률 예측력이 있고 30분 안에 사라지므로 보유 상한이 8분입니다.

**공통 리스크 규칙** — BTC 15분봉 20이평 대비 **-0.2% 초과 하회** 시 모멘텀·돌파 9전략 신규 진입 차단(보유 유지).
역추세 1전략(`panic_bounce`)만 `btc_filter: False` 예외로 하락 추세에서도 진입합니다.
손절 시에만 전략별 쿨다운(3~5분)이 걸리고, 그 쿨다운도 계좌별로 독립입니다.

**스테이블코인 전면 제외 (`market_filter.py`)** — `KRW-USDT`·`KRW-USDC`·`KRW-DAI` 등 달러·유로 페그
스테이블코인은 페그에 고정돼 목표 익절 도달이 불가능하고 변이가 0이라 밴드 수축·유동성 상위 조건만
늘 통과해 **수수료만 누수**됩니다. 단일 정의(`STABLE_BASES`)를 `ws_stream`(구독) · `candles`(1분봉 수집) ·
`sniper_engine`(신호 판정·체결)이 모두 참조해 원천 차단하고, 보유 중이면 다음 틱에 `STABLE_EXIT`으로 정리합니다.

체결 가정: 목표 익절은 목표가 체결(초과분 미반영·보수적), 손절·트레일링·시간초과는 관측 틱 가격에서
호가 0.5틱을 뺀 가격으로 체결. 수수료는 매수·매도 각 0.05%(왕복 0.10%).

- **호스팅:** Render Free Web Service (Python FastAPI) — 수동 배포(`Clear build cache & deploy`)
- **가동 유지:** 10분 주기 `/health` 핑
- **WebSocket:** `ws_stream.py` 1개 (유의종목 제외 · 24h 거래대금 30억↑ · 15분 롤링 윈도우)
  — 틱에서 15초·10초·3분·10분 창 지표(거래대금·BID 비율·반등·눌림·VWAP·**10분 레인지·박스 고점·최대 매수 체결**)를 한 번에 계산
- **1분봉 캐시:** `candles.py` — 거래대금 상위 **15종목만** 별도 저속 스레드가 **종목당 60초 주기**,
  요청 간 **0.25초 슬립**(실효 4 req/s ≤ 업비트 10 req/s)으로 순환 수집 → 볼린저 전략용
- **대시보드:** `GET /dashboard` — 수익률 리더보드(1~10위) + 전략 카드 + 상세(포지션·규칙·매매내역) + v4.0 진단 탭
- **상태 API:** `GET /api/status` — `strategies`(10전략), `leaderboard`, `aggregate`, `league_all_time`(라이브+퇴출 아카이브 합산)
- **데이터 보존:** 비공개 GitHub Gist 동기화 — **토큰·Gist ID 는 코드에 없고 환경변수로만** 받습니다.

### 상태 승계·보호 규칙

- v4.0 상태를 읽으면 `3m`·`10m`·`panic_bounce`는 규칙·잔고·전적·포지션을 **손대지 않고** 승계하고,
  `30m`·`pullback_reentry`·`vwap_breakout`·`bb_squeeze`는 잔고·전적만 승계한 뒤 규칙을 교체합니다
  (재설계 시점에 물려 있던 포지션은 다음 틱에 `RESET_EXIT`으로 정리). 퇴출 3전략은 `v4_archive`에 보존되고
  신규 3전략은 200만 원으로 시작합니다.
- **v5.0 → v5.1 → v5.2**는 `migrate_from_v5()`로 **무손실 승계**합니다 — 10계좌 잔고·전적·포지션·매매내역·쿨다운과
  `v4_archive`·v4→v5 승계 이력·`v5_fix`(v5.0→v5.1 기록)를 그대로 이어받고, 규칙 파라미터만 v5.2 정의로 교체합니다.
  파라미터가 실제로 바뀐 계좌만 1일 거래 예산 시계(`rules_effective_from`)를 승계 시점으로 옮기고,
  승계 내역은 상태의 `v5_2_fix`에 기록됩니다(규칙이 그대로인 `30m`·`tape_sweep`은 시계도 유지).
- Gist가 설정된 환경에서 원격 상태 로드에 실패하면 **매매도 원격 저장도 하지 않고**(`STATE_SYNC_WAIT`)
