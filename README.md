# 🎯 도현의 테크브리프 · 가상 거래량 스나이퍼 봇 v3.1 (24/7 Cloud)

업비트 실시간 체결(WebSocket trade) 스트림을 받아 **1.5초 주기**로 거래대금 폭발 초입을 포착하는
모의투자 초단타 봇 + 실시간 웹 대시보드입니다. 실계좌·실주문 없이 가상 시드로만 운용합니다.

## ⚖️ v3.1 구조 — 15초 거래대금 문턱별 3계좌 병렬

웹소켓 연결 1개와 BTC 추세 체크는 공유하고, 판단 루프에서 **잔고·포지션·전적·쿨다운이 완전히 분리된 3개 계좌**를 동시에 운용합니다.

| 슬롯 | 성향 | 15초 거래대금 문턱 | 시드 |
|---|---|---|---|
| `30m` | 보수형 · 대형 슈팅 | ≥ 30,000,000원 | 2,000,000원 |
| `10m` | 균형형 · 중형 슈팅 | ≥ 10,000,000원 | 2,000,000원 |
| `3m` | 공격형 · 초민감 스캘핑 | ≥ 3,000,000원 | 2,000,000원 |

## ⚙️ 매매 규칙 (3계좌 공통, 금액 문턱만 다름)

1. **BTC 필터** — BTC 15분봉 20이평 대비 -0.2% 초과 하회 시 신규 진입 차단
2. **폭발 판정** — 최근 15초 거래대금 ≥ 직전 3분 평균 15초 거래대금 × 4.0
3. **금액 문턱** — 최근 15초 거래대금 ≥ 계좌별 문턱 (3,000만 / 1,000만 / 300만)
4. **매수 체결 우위** — 최근 15초 매수(BID) 체결 금액 비율 ≥ 70%
5. **초입 구간** — 3분 전 가격 대비 +0.3% ~ +3.0% (뒷북 추격 차단)
6. **청산** — 목표 +2.5% · 트레일링(+1.5% 도달 후 고점 대비 -0.4% 반락) · 손절 -1.8%(5분 쿨다운) · 최대 보유 20분

## 🚀 아키텍처

- **호스팅:** Render Free Web Service (Python FastAPI) — `autoDeploy: true`
- **가동 유지:** 10분 주기 `/health` 핑
- **대시보드:** `GET /dashboard` — 3계좌 비교 카드 + 계좌별 상세 + v1/v2 아카이브
- **상태 API:** `GET /api/status` — `tiers`(`30m`/`10m`/`3m`)별 평가자산·수익률·전적·포지션·매매내역
- **데이터 보존:** 비공개 GitHub Gist 동기화 (`GIST_TOKEN`, `GIST_ID` 환경변수 전용)
